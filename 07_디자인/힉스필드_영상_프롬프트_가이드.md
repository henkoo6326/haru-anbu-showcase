```
1단계: 이미지 먼저 생성 (Soul 2.0 또는 Nano Banana Pro)
```

## 프롬프트 작성 팁 (힉스필드 전용)

### 잘 먹히는 키워드

| 카테고리 | 키워드 |
|---------|--------|
| **퀄리티** | `4K`, `cinematic`, `high quality`, `photorealistic` |
| **조명** | `soft diffused lighting`, `golden hour`, `warm lighting`, `no harsh shadows` |
| **카메라** | `dolly in`, `slow pan`, `static camera`, `close-up`, `medium shot`, `tracking shot` |
| **분위기** | `warm atmosphere`, `melancholic`, `hopeful`, `professional`, `serene` |
| **색감** | `warm color temperature`, `shallow depth of field`, `soft film grain`, `bokeh` |
| **스타일** | `minimal`, `clean`, `modern`, `elegant` |

### 피해야 할 것

- 한 프롬프트에 너무 많은 동작 넣지 말 것 (1~2개면 충분)
- 한국어 프롬프트 사용 금지 (영어만)
- 텍스트 렌더링을 기대하지 말 것 (한글 텍스트는 편집 때 자막으로 추가)
- 너무 복잡한 카메라 무빙 지양 (하나의 명확한 움직임)

### reference 이미지 활용법

1. 앱 목업 PNG를 업로드하면 → 해당 UI를 기반으로 영상 생성
2. 캐릭터 일러스트를 업로드하면 → 해당 스타일 유지
3. 로고 SVG를 PNG로 변환 후 업로드 → 로고 기반 모션 생성
