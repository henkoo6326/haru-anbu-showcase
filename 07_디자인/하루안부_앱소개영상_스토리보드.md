# 하루안부 앱 소개 영상 스토리보드

> **컨셉**: "한 눈에 보는 하루안부"
> **길이**: 60~90초
> **형식**: 앱 UI 데모 중심 + 타이포 모션 + 미니멀 실사 인서트
> **목적**: 앱이 뭔지, 뭘 할 수 있는지, 왜 써야 하는지를 빠르게 전달
> **작성일**: 2026.04.12
> **톤**: 카카오뱅크 "같은 것을 다르게" + 카카오헬스케어 PASTA 하이브리드

---

## 기존 홍보영상과의 차이점

| 구분 | 홍보영상 (2분) | 앱소개영상 (60~90초) |
|------|---------------|---------------------|
| **목적** | 감동 + 브랜드 인지 | 기능 이해 + 다운로드 유도 |
| **주인공** | 3인의 하루 이야기 | 앱 자체 |
| **비율** | 실사 55% / 앱 UI 25% | 앱 UI 60% / 타이포 25% / 실사 15% |
| **BGM** | 오케스트라 + 어쿠스틱 | 미니멀 일렉트로닉 + 피아노 |
| **내레이션** | 감성적 스토리텔링 | 짧고 직관적 안내 |
| **사용 처** | 유튜브, 발표, 소셜 | 앱스토어 프리뷰, 랜딩페이지, 인스타 릴스 |

## 영상 구성 요약

```
[0-8초]   HOOK — 한 줄 질문 + 스플래시
[8-20초]  INTRO — 3자 연결 컨셉 요약
[20-45초] FEATURE TOUR — 핵심 기능 4개 시연
[45-55초] AI — AI 기능 하이라이트
[55-70초] TRUST — 수치 + 신뢰
[70-80초] CTA — 다운로드 유도 + 엔딩
```

| **감정** | "AI가 진짜 도와주네", 잠깐 긴장 → 빠른 안심 |
| **사용 에셋** | `v7_ai-home/guardian/g00-ai-home.html` (스크린샷), `guardian/g04-ai-guide.png`, `guardian/g06-alert.png` |
