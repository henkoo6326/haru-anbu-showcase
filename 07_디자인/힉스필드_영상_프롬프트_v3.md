# 하루안부 홍보영상 — 스토리보드 & 프롬프트 v3.0

> **v2 → v3 변경사항:**
> - 앱 화면은 AI 생성 X → 편집에서 목업 모션으로 제작 (Jitter/CapCut/AE)
> - 내레이션 + 키네틱 타이포 하이브리드 구성
> - Apple 스타일 빠른 교차편집 (5초 AI 클립에 최적화)
> - BGM 1곡으로 감정 곡선 설계
> - 실사 인물 클립 ↔ 앱 목업 모션을 명확히 분리

---

## 최종 구성 원칙

| 항목 | 결정 |
|------|------|
| **총 길이** | 90초 (1분 30초) — 2분은 이탈률 높음 |
| **내레이션** | 있음 — 따뜻한 여성 목소리, "~했어요" 어투 |
| **타이포** | 핵심 키워드만 키네틱 모션 (내레이션과 동기화) |
| **앱 화면** | 편집에서 목업 모션 제작 (AI 생성 X) |
| **실사 장면** | Kling 3.0 AI 생성 (캐릭터 인플루언서 활용) |
| **BGM** | 피아노 기반 1곡 (마이너→메이저 전환) |
| **컬러** | 전체에 따뜻한 LUT 통일, Act1만 desaturated |
