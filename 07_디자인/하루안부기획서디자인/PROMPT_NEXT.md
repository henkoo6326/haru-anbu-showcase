## 추가 옵션 (상황별로 덧붙일 것)

**A. 특정 페이지부터 바로 시작하려면:**
> 이번엔 XX페이지부터 할거야. 레퍼런스는 [이미지 첨부]

**B. 전체 슬라이드 맵 먼저 보고 싶으면:**
> 시작 전에 전체 슬라이드 ID랑 페이지 번호 매핑 스캔해서 표로 줘.

**C. 번호 재정리부터 하려면:**
> 먼저 sdesign/sdesign2가 둘 다 44/50으로 되어 있으니 전체 페이지 번호 재정리부터 해줘.
